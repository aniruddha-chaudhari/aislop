# AI Draft & Progressive Preview System

## Overview
This document describes the AI Draft generation and progressive preview system implemented for the timeline editor.

## AI Draft Generation

### What It Does
When the user clicks "Generate AI Draft", the system:

1. **Analyzes Audio Session**
   - Loads all dialogue audio files from the selected audio session
   - Uses WhisperX for precise sentence-level timestamps

2. **Generates Timeline Components**
   - **Subtitle Clips**: One clip per dialogue with accurate timing and speaker info
   - **Image Overlay Clips**: Based on AI analysis of dialogue content
     - Includes `assetId` for identification
     - May include `path` if image was generated by AI embedder
     - Position (x, y) and scale pre-calculated
   - **Character Clips**: Based on speaker identification
     - Maps speakers to character images (e.g., "Stewie" → `character_images/Stewie_Griffin.png`)
     - Position and timing based on when character speaks

3. **Timeline Structure**
   ```
   Timeline
   ├── Audio Track (locked)
   ├── Subtitle Track
   │   └── SubtitleClips (one per dialogue)
   ├── Overlay Track
   │   └── OverlayClips (AI-suggested images)
   └── Character Track
       └── CharacterClips (speaker avatars)
   ```

### Endpoints
- `POST /api/project/:id/ai-draft`
- Updates project with generated timeline
- Timeline is fully editable after generation

## Progressive Preview System

### How It Works

The preview system renders **whatever currently exists in the timeline**, progressively showing more as content is added:

#### Stage 1: Template Only
- **State**: Fresh project, no audio session
- **Preview Shows**: Template video looping

#### Stage 2: Template + Audio
- **State**: Audio session selected, no AI draft yet
- **Preview Shows**: Template video + dialogue audio synchronized

#### Stage 3: Template + Audio + Timeline Elements
- **State**: AI draft generated
- **Preview Shows**:
  - ✅ Template video
  - ✅ Dialogue audio
  - ✅ Subtitles (from timeline subtitle clips)
  - ✅ Character images (if they exist in `character_images/`)
  - ⚠️ Overlay images (only those with `path` set)

#### Stage 4: Fully Populated Timeline
- **State**: User has uploaded images for overlay clips
- **Preview Shows**: Everything above + newly uploaded overlay images

### Technical Implementation

**Backend (timelineCompiler.ts)**:
```typescript
// Progressive rendering logic:
1. Check if timeline exists
2. If no timeline → render template + audio only
3. If timeline exists:
   - Generate ASS subtitles from subtitle clips
   - Add overlay images (only clips with valid `path`)
   - Add character images (only if found in character_images/)
   - Skip missing assets (logs warning, continues)
```

**Quality Modes**:
- **Preview**: `ultrafast` preset, CRF 28, 720p (fast for iteration)
- **Final Export**: `medium` preset, CRF 23, 1080p (high quality)

### Endpoints

**Generate Preview**:
```
POST /api/project/:id/preview
```
- Reads current `project.timeline` state
- Generates low-res preview video
- Returns URL to preview video

**Serve Preview**:
```
GET /api/project/:id/preview-video
```
- Serves the generated preview MP4
- Used by `<video>` element in CanvasPreview

### Frontend Integration

**EditorLayout.tsx**:
```typescript
// When user clicks play:
1. Check if preview needs regeneration
2. Call POST /api/project/:id/preview
3. Get preview URL
4. Set previewVideoSrc
5. Play video in CanvasPreview
```

**CanvasPreview.tsx**:
```typescript
// Video source selection:
videoSrc = previewVideoSrc || templateVideoSrc

// When playing:
- If previewVideoSrc exists → plays composite preview
- Otherwise → plays template video only
```

## Image Upload System

### Properties Panel (TextPropertiesPanel.tsx)

When an overlay clip is selected:

1. **Shows Current State**:
   - If `clip.path` exists → shows image thumbnail
   - Otherwise → shows "No image uploaded" placeholder

2. **Upload Flow**:
   ```
   User selects file
   → POST /api/project/:id/upload-image
   → Image saved to storage/images/{sessionId}/{assetId}.png
   → Clip.path updated with full path
   → Timeline auto-saved
   → Next preview generation includes this image
   ```

3. **Endpoint**:
```
POST /api/project/:id/upload-image
Content-Type: multipart/form-data

Fields:
- image: File (the image file)
- assetId: String (from overlay clip)
```

## Asset Requirements

### Character Images
Location: `backend/character_images/`

Expected files:
- `Stewie_Griffin.png`
- `peter.png`
- (Add more as needed)

### Uploaded Overlay Images
Location: `backend/storage/images/{sessionId}/`

Format: `{assetId}.png` (or .jpg, .jpeg)

## Timeline Compilation Flow

```
User Action → Timeline State → Preview Shows
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Create project → Empty timeline → Template loop
Select audio → Timeline = null → Template + audio
Generate AI draft → Timeline with clips → + Subtitles + Characters
Upload image for overlay → Clip.path set → + That overlay image
Edit position/timing → Clip properties changed → Updated positions
Export final → Full quality render → High-quality MP4
```

## Key Features

1. **Progressive Enhancement**: Preview shows what's available
2. **Fast Iteration**: Preview mode (720p, ultrafast) for quick feedback
3. **Skip Missing Assets**: Warns but doesn't fail if images missing
4. **Real-time State**: Always reflects current timeline JSON
5. **Incremental Uploads**: Add images one at a time, preview updates
